# Project thumbnail drop folder

Take a screenshot of an interesting image or section from each project PDF, crop it to roughly landscape (4:3 works well), and save it here as a PNG using these exact names:

- `live-fast-die-young.png` — Live Fast Die Young
- `talking-plants.png` — Talking Plants
- `cell-calcium-sensor.png` — Cell Calcium Sensor
- `guessing-hand-gestures.png` — Guessing Hand Gestures

The site is already mapped to these filenames. Until a screenshot is added, it automatically falls back to the current plant or DNA motif, so no page will show a broken image.

The Argentina project continues to use `/public/docs/argentina/placeholder.png`.
