## Filename signals

Renaming is optional. Helpful signals include:

- `good` — prioritise
- `process` — experimental or construction process
- `hardware` — device or automation
- `imaging` — microscope or image-analysis output
- `result` — visible experimental result
- `failed` — useful failure or iteration
- `private` — never publish

Codex should preserve the originals locally, select and trim useful passages, remove private metadata, create compressed web copies, and pause other page media when a video plays.
